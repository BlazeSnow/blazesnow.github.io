# <TitleIcon icon="windows" /> 磁盘清理

> 从计算机的硬盘中清除不必要的文件。可以使用命令行选项指定 Cleanmgr 清理临时文件、Internet 文件、下载的文件和回收站文件。

1. 按下 <WinKey /> + <KeyCap char="R" />
2. 输入以下命令并回车：

```shell
cleanmgr
```

> [!WARNING]
> Cleanmgr可能会删除驱动程序和系统的旧版文件。若需要回退旧版驱动程序和系统，请注意取消勾选相关项目。
